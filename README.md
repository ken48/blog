# Личный блог

Сайт: https://ken48.github.io/blog/

## Публикация

Добавляйте и редактируйте заметки в корне репозитория как раньше:
`2026-09-09 Название заметки.md`. После отправки изменений в `main`
GitHub Actions подготовит посты, соберёт Chirpy и опубликует сайт.
Исходные заметки не изменяются. Пустые файлы и файлы без даты не публикуются.
Будущие даты Jekyll публикует только при сборке после наступления даты;
для этого можно вручную запустить Build and Deploy в Actions.

Теги необязательны. Чтобы добавить их, поместите в начало заметки:

```yaml
---
tags: [работа, технологии]
---
```

Заголовок и дата берутся из имени файла; их можно переопределить в этом же
блоке. `published: false` исключает заметку из сайта, но файл остаётся
видимым в публичном репозитории. Ссылки на посты сохраняются при изменении
текста, но меняются при переименовании исходного файла.

## Настройки

- `site/_config.yml`: имя, описание, язык и адрес сайта.
- `site/_tabs/about.md`: страница «О сайте».
- `site/_data/contact.yml`: ссылки в боковой панели.
- Комментарии пока выключены; провайдер подключается в `_config.yml`.
- Тема: [Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy),
  основа: [Chirpy Starter](https://github.com/cotes2020/chirpy-starter).

Один раз выберите Settings → Pages → Build and deployment → Source →
GitHub Actions. После объединения PR сайт публикуется автоматически.
Проверки PR собирают сайт без публикации.

## Локальный просмотр (необязательно)

Нужны Ruby 3.4 и Bundler:

```sh
ruby tools/prepare-posts.rb
cd site
bundle install
bundle exec jekyll serve
```

Открыть http://127.0.0.1:4000/blog/.
